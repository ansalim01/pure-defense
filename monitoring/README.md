# Аптайм-монитор (Cloudflare Worker)

Следит за `https://dez-profi-kazan.ru/` и шлёт в Telegram:

- 🔴 **когда сайт упал** (не отвечает, таймаут, или код ≥ 400);
- 🟢 **когда поднялся** (с длительностью простоя).

Работает на edge Cloudflare — **снаружи твоего VPS**, поэтому ловит даже полное
падение сервера. Состояние хранится в KV: сообщение приходит один раз на падение
и один раз на восстановление, без спама. Перед алертом ждёт `FAIL_THRESHOLD`
неудач подряд, чтобы одиночный сбой сети не дёргал зря.

Бесплатно: при проверке раз в 5 минут это ~8 600 запусков/мес, лимит бесплатного
плана — 100 000/день.

---

## Установка (один раз)

Всё выполняется из папки `monitoring/`.

### 1. Wrangler и вход в Cloudflare

```bash
npm install -g wrangler   # если ещё нет
wrangler login            # откроется браузер, авторизуйся в своём аккаунте Cloudflare
```

### 2. Создать KV-хранилище для состояния

```bash
wrangler kv namespace create MONITOR_KV
```

Команда выведет строку вида:

```
[[kv_namespaces]]
binding = "MONITOR_KV"
id = "abc123def456..."
```

Скопируй `id` и вставь его в `wrangler.toml` вместо `<KV_NAMESPACE_ID>`.

### 3. Прописать chat_id и токен бота

`TELEGRAM_CHAT_ID` — впиши в `wrangler.toml` (это не секрет). Возьми тот же
chat_id, что используется в деплое (`secrets.TELEGRAM_CHAT_ID` / `.env`).

`TELEGRAM_BOT_TOKEN` — это секрет, в файлах его не храним:

```bash
wrangler secret put TELEGRAM_BOT_TOKEN
# вставь токен того же бота, что шлёт уведомления о деплое
```

### 4. Задеплоить

```bash
wrangler deploy
```

Cron включится автоматически — первая проверка пройдёт в ближайший слот `*/5`.

## Проверить, что работает

После деплоя у воркера есть URL вида `https://pure-defense-monitor.<твой-сабдомен>.workers.dev`.

- `GET /` — показать текущее состояние (up/down, последняя проверка);
- `GET /run` — прогнать проверку прямо сейчас (удобно для теста).

Боевой тест «падения»: временно укажи в `wrangler.toml`
`SITE_URL = "https://dez-profi-kazan.ru/нет-такой-страницы-12345"`, выстави
`FAIL_THRESHOLD = "1"`, задеплой, открой `/run` пару раз — должно прийти 🔴.
Потом верни настройки обратно и задеплой снова — придёт 🟢.

## Настройки (`wrangler.toml`)

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `crons` | как часто проверять | `*/5 * * * *` (раз в 5 мин) |
| `SITE_URL` | какой адрес проверять | `https://dez-profi-kazan.ru/` |
| `FAIL_THRESHOLD` | неудач подряд до алерта | `2` |
| `TIMEOUT_MS` | таймаут одного запроса | `15000` |
| `MUST_INCLUDE` | (опц.) строка, которая должна быть на странице | выкл. |

Эффективная задержка алерта ≈ `FAIL_THRESHOLD × интервал`. С дефолтами —
сайт лежит ~10 минут, прежде чем придёт 🔴 (защита от ложных срабатываний).

После любой правки `wrangler.toml` или `worker.js` — снова `wrangler deploy`.

## Логи

```bash
wrangler tail   # живой поток логов воркера (видно каждую проверку)
```
